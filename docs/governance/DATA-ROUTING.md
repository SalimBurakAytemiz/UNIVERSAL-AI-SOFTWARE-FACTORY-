# Data Routing

PUBLIC: approved broad providers may be allowed.  
INTERNAL: approved providers only.  
CONFIDENTIAL / RESTRICTED / PII / FINANCIAL: explicit allowlist.  
SECRET: local-only by default.

Secrets are not ordinary prompt context.
