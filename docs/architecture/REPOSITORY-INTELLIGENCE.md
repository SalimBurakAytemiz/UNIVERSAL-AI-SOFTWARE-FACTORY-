# Repository Intelligence & Context Fabric

Required components:
- file index
- symbol/AST/LSP index
- module/dependency graph
- requirement-to-code map
- test-to-code map
- change impact graph
- semantic retrieval
- repository summary cache
- structured log compressor
- context compiler
- checkpoint index
- provenance of indexed commit

AI receives the smallest sufficient context, not the whole repository by default.
