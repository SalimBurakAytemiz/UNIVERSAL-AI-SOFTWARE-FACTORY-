# Universal Assurance

User Journey != Adversarial Engineering. Both are needed.

Cross-layer chain:
`ACTION -> UI -> API -> AUTHZ -> BUSINESS RULE -> DATA -> EVENT -> OBSERVABILITY -> USER RESULT`

Coverage includes:
functional, regression, API, contract, auth/authz, state machine, business logic, DB/data, visual, accessibility,
compatibility, mobile, desktop, browser, performance, resilience, security, recovery, privacy, supply-chain and audit.

Every report states verified, partial, unverified and unknown surfaces.
