# Technology Knowledge Graph

Technology kaydı yalnız isim değildir.

Her technology profile:
- identity + aliases
- group/type/ecosystem
- official source policy
- version/LTS/EOL policy
- knowledge facets
- interoperates-with / built-on / alternatives
- common toolchain
- test/security/performance/operations expectations
- migration/upgrade semantics
- freshness/recertification triggers

Registry dışı teknoloji:
`Detect -> Official source -> Version pin -> Sandbox -> Model knowledge -> Golden/Holdout -> Independent review -> Certify`.

Bu sayede "her teknolojiyi bil" hedefi sonsuz hard-coded liste yerine geniş seed + sürekli kontrollü öğrenme ile karşılanır.
