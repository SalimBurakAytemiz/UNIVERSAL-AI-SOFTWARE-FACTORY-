# Polyglot Language & Build Toolchain Fabric

Toolchains are registered, health-checked and mission-selected.

Initial ecosystems:
JS/TS, Python, Java/Kotlin, .NET/C#, Go, Rust, C/C++, Swift/Objective-C, Dart/Flutter,
PHP, Ruby, Scala, Elixir/Erlang, Shell/PowerShell and SQL.

A language/toolchain is not certified merely because the command exists.
Golden projects and compile/test/eval evidence are required.
