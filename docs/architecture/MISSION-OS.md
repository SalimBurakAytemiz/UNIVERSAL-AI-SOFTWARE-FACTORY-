# Mission OS

Mission contract:
objective, success criteria, customer/project/target, scope/exclusions, authorization provenance,
environment, data class, allowed techniques, risk, budget, capabilities, tools/resources, evidence,
stop conditions and approval gates.

Lifecycle:
`DRAFT -> PREFLIGHT -> AUTHORIZED -> PLANNED -> EXECUTING -> VERIFYING -> REVIEWING -> REMEDIATING -> REGRESSION -> REPORTING -> COMPLETE`

Policy failure => BLOCKED.  
Critical unresolved automation => FOUNDER_ATTENTION_REQUIRED.
