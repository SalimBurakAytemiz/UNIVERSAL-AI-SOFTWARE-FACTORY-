# Agent Competency Model V2

Her agent:

`Company Literacy + Engineering Foundation (teknikse) + Primary Packs + Secondary Packs + Adjacent Awareness + Role Mastery + Mission Stack + Dynamic Gap Acquisition`

## Derinlik eksenleri

0 NOT_REQUIRED  
1 AWARENESS  
2 WORKING_KNOWLEDGE  
3 IMPLEMENTATION  
4 DEBUGGING  
5 ADVANCED_ENGINEERING  
6 ARCHITECTURE_DECISION  
7 PRINCIPAL_REVIEW

Tek sayı kullanılmaz. Fundamentals, implementation, debugging, testing, architecture,
interoperability, security, performance, operations, migration, review ve technology-selection ayrı tutulur.

## Çok yönlülük

Çok yönlülük = her agentın her frameworkü aynı derinlikte kodlaması değildir.

- Specialist kendi alanında derin.
- Lead specialist çıktısını teknik olarak sorgular.
- Principal alternatifleri karşılaştırır.
- Head bütün domain risklerini görür.
- Council disiplinler arası trade-off çözer.
- Founder yalnız gerçek kritik kararı verir.
