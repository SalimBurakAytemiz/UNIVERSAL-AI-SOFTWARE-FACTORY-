# Extension Architecture

Unknown need flow:

`MISSING_CAPABILITY -> classify primitive vs adapter -> research -> sandbox -> adapter/domain/toolchain implementation -> tests -> security review -> certification -> registry -> reuse`

Most future additions should be one of:
- Tool Adapter
- Provider Adapter
- Resource Kind
- Skill
- Domain Pack
- Mission Blueprint
- Language Toolchain
- Studio plugin
- Control Tower module

Only a genuinely new primitive justifies core architecture change.
