# Technology Decision Engine

Inputs: Project/System Genome, functional requirements, NFRs, domain obligations, team/certified skills, target platforms, data class, cost, time, operations and exit constraints.

Outputs: candidate set, evidence matrix, experiments/benchmarks, risks, dissent, ADR and re-evaluation triggers.

No universal “best technology” exists. Decision is mission/project specific.
