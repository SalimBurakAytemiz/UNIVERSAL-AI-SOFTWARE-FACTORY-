# Agent Technical Genome

Her agent rolü `registries/agent-skill-matrix.json` ve kendi `organization/agents/*.json` profili ile tanımlıdır.

Bir modelin genel eğitiminden gelen “biliyorum” ifadesi yetkinlik değildir. Mission gerektirdiği skill için certification state, freshness, tool health ve evidence kontrol edilir.

Skill derinliği: Awareness -> Working -> Advanced Execution -> Principal Review -> Principal Decision.

Eksik skill: declare gap -> official-source research -> sandbox -> implementation/debug/test -> golden -> hidden holdout -> independent review -> certification.
