# Leadership Hierarchy

Founder son kritik otoritedir; Founder agent değildir.

Default flow:
`Specialist -> Subteam Lead -> Department Head -> Cross-Functional Council -> Founder only if required`

Head teknik kaliteyi kontrol eder, council disiplin çatışmasını çözer, independent reviewer milestone bütünlüğünü denetler. Hiçbir çoğunluk oyu evidence'ın yerine geçmez.
