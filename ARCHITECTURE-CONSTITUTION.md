# Architecture Constitution

## Product identity
The system is the software company operating system itself, not merely infrastructure.

Permanent verbs:
`UNDERSTAND -> ASSURE -> BUILD -> OPERATE -> REPAIR -> LEARN -> REPORT`

## Immutable rules

DEFAULT DENY.  
LEAST PRIVILEGE.  
EXPLICIT CAPABILITIES.  
SEPARATION OF DUTIES.  
HUMAN FINAL CONTROL.  
AUDIT EVERYTHING.  
NO CLAIM WITHOUT EVIDENCE.  
NO FAKE SUCCESS.  
NO SILENT SPENDING.  
NO SILENT PRODUCTION ACTION.  
NO SILENT AUTHORITY ESCALATION.  
NO SELF-ASSERTED TRUST.  
NO SELF-ASSERTED INDEPENDENT REVIEW.  
SELF-LEARNING != SELF-TRUSTING.  
REGISTER EVERYTHING. ACTIVATE ONLY WHAT THE MISSION NEEDS.

## Founder
Human Founder is final authority for Risk-5, destructive production, irreversible migration,
critical spending, critical legal/security/financial decisions and global kill.

Founder is not counted as an agent.

## Source of truth
Git + repository + `.ai/` are canonical.
Chat is not project memory.

## Mission above Project
A Mission may target existing systems without creating a project, or create/manage multiple projects.

## Reality model
SPECIFICATION != IMPLEMENTATION != TEST != EVIDENCE != RUNTIME VERIFICATION != PRODUCTION VERIFICATION.

A folder, schema, registry row, prompt or test source is never enough to claim implementation.

## Review
Claude = primary builder.  
Codex = independent reviewer.  
Deterministic tools = first validation layer.

Builder cannot independently certify its own code.

## Customer boundary
Customer contexts, repos, targets, credentials, evidence, artifacts, costs and memory are isolated by default.

## Security assessment
Active security/performance/reverse-engineering assessment requires authorization provenance,
scope lock, target allowlist, technique policy, environment, data rules, ceilings and stop conditions.

Prefer non-destructive proof.

## External research clean-room
External code/content can be researched in isolated workspaces.
Raw external source does not silently enter generated source.

`LEARN EVERYTHING. COPY NOTHING. BUILD WHAT THE MISSION ACTUALLY NEEDS.`

## Data/model routing
"Free" is a cost property, not a trust property.
Restricted data follows explicit allowlists; SECRET is local-only by default.

## Learning
`OBSERVE -> EVIDENCE -> NORMALIZE -> DEDUPE -> CONFLICT_CHECK -> VALIDATE -> REVIEW -> CERTIFY -> REUSE`

Learning cannot grant authority or turn failure/unreviewed code into a positive certified pattern.

## Unknowns and future gaps
UNKNOWN remains UNKNOWN without evidence.

New tools/providers/languages/domains should normally enter through Adapter SDK / Toolchain Registry / Domain Pack SDK,
not by rewriting the core architecture.

## Turkish operability
Canonical technical identifiers are English.
Founder explanations are Turkish.
Every eligible human-maintained source/config/doc file contains a syntax-safe literal `//TR` purpose explanation.

## Fail closed
When critical authority, scope, data policy, evidence or safety is uncertain: fail closed.
## Technical competence constitution
- AGENT TITLE != COMPETENCE.
- MODEL PRETRAINING CLAIM != CERTIFIED SKILL.
- Every active agent has a Technical Genome, skill depth, standards, tools, review chain and certification state.
- Missing skill must be declared and acquired through research/sandbox/evaluation before critical use.
- Specialist work is technically reviewed by lead/head; cross-functional trade-offs go to council.
- Technology selection is project-specific and evidence-based.
- Consensus != truth; evidence and reproducibility dominate votes.
