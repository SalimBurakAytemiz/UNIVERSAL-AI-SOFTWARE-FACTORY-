# `//TR` File Purpose Standard

Examples:

TypeScript/Java/etc:
```ts
// //TR: Bu dosya ... amacıyla yazılmıştır.
```

PowerShell/Python/YAML:
```text
# //TR: Bu dosya ... amacıyla yazılmıştır.
```

Markdown/HTML:
```html
<!-- //TR: Bu dosya ... amacıyla yazılmıştır. -->
```

JSON:
```json
{ "//TR": "Bu dosya ... amacıyla yazılmıştır." }
```

Binary/generated/vendor/lock/minified files are exceptions and must be registered, not mutated.
