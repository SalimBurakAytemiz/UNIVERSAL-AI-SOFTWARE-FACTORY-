# Definition of Done

A milestone is complete only when:

- frozen milestone contract exists and its digest is recorded
- actual changes stay inside allowed scope
- protected trust-root remains intact
- real executable/runtime work required by the milestone exists
- meaningful tests execute
- negative/failure paths required by the contract execute
- canonical deterministic validation passes
- security/secret checks required by the contract pass
- evidence is linked to run/commit/environment/tool versions
- no unresolved admissible blocker remains
- environment gaps are explicitly recorded
- Codex returns a schema-valid review result
- reviewer independence is sufficient for the risk profile
- CLEAN is bound to exact reviewed commit and review bundle digest
- reviewed tip is merged without modification
- post-merge verification passes
- scheduler/run/evidence state is checkpointed

A directory, prompt, registry row, design doc or unexecuted test source is not IMPLEMENTED.
