# Technology Decision Standard

Flow:
`Founder intent -> Project/System Genome -> requirements/NFR -> constraints -> candidate discovery -> evidence -> experiments/benchmarks when needed -> Security/QA/SRE/Business reviews -> dissent -> ADR -> approval boundary -> implementation -> outcome learning`

Every decision records alternatives, rejected reasons, assumptions, constraints, total cost, operability, testability, security, scalability, migration/exit plan, license/IP, ecosystem lifecycle and certified internal competency.

No agent may select a framework because it is familiar or popular without project-fit evidence.
