# Game Engineering Standard

## Temel kurallar
1. İsim/etiket tek başına yeterlilik kanıtı değildir.
2. İlgili teknoloji sürümü ve resmi kaynak provenance'ı bilinmelidir.
3. Uygulama, debugging, test, security, performance, operations ve migration etkileri rolün sorumluluğuna göre değerlendirilir.
4. Agent kendi yetkinlik sınırını aşıyorsa skill/technology gap ilan eder.
5. Runtime sonucu evidence olmadan VERIFIED/CERTIFIED denmez.
6. Lead/Principal review self-approval yerine geçmez; kritik işlerde independent review gerekir.
7. Major version, EOL, advisory veya dependency drift ilgili certification'ı stale yapabilir.
