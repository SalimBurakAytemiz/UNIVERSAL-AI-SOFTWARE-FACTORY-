# Agent Technical Competency Standard

Agent = Role + Competency Pack + Role Focus Skills + Tool Access + Standards + Playbooks + Domain Pack + Mission Context + Permissions + Evidence + Certification.

Depth model:
1. AWARENESS
2. WORKING
3. ADVANCED_EXECUTION
4. PRINCIPAL_REVIEW
5. PRINCIPAL_DECISION

Skill evaluation must include knowledge, implementation, debugging, tests, review, golden task and hidden holdout where applicable.

An agent that lacks a required skill must declare a gap and use the Missing Skill Acquisition playbook. It may not bluff competence from model pretraining.
